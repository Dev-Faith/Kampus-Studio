Quick reference for when to use Middleware, Guards, Interceptors, Pipes, and Exception Filters.

When do I use which building block?

Construct Single Responsibility Knows Target Handler? Can Transform Response?
Middleware Mutate raw req/res (e.g. x-request-id) No (runs before routing) No
Guard Allow or deny access (boolean or throw 401/403/429) Yes (ExecutionContext + Reflector) No
Interceptor Wrap execution before & after via RxJS stream Yes (ExecutionContext) Yes (map, tap, timeout, short-circuit cache)
Pipe Transform or validate a single route argument Receives ArgumentMetadata Transforms input argument only
ExceptionFilter Turn thrown errors into structured HTTP error JSON Receives ArgumentsHost Replaces error response

HTTP Status Codes Every Backend Engineer Must Know

Code NestJS Exception When to Use It
200 / 201 / 204 — 200 OK, 201 Resource Created, 204 Deleted (no body)
400 Bad Request BadRequestException Malformed input, failed DTO validation or pipe parsing
401 Unauthorized UnauthorizedException Missing, invalid, or expired authentication credentials
403 Forbidden ForbiddenException Authenticated, but insufficient role or not resource owner
404 Not Found NotFoundException Entity ID does not exist (or hidden behind disabled feature flag)
408 Request Timeout RequestTimeoutException Downstream call exceeded SLA in TimeoutInterceptor
409 Conflict ConflictException Duplicate unique key (e.g. email already registered)
422 Unprocessable UnprocessableEntityException Valid syntax, but breaks a domain rule (e.g. insufficient funds)
429 Too Many Requests ThrottlerException Client exceeded rate limit window; include Retry-After
